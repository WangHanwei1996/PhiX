# GFA_evo 参数标定方案

> 对象：`applications/solvers/GFA_binary/GFA_evo.cu`（CH + 双序参量 AC：成分 `c`、晶体 `phi`、非晶 `eta`）。
> 用途：把方程里每个自由参数对应到**一个可测物理量**上，给出标定靶子、数据来源与反解公式。
> 配套细节推导：
> - 界面（`w`,`eps_sq`,`beta_sq`）→ [`doc/interface_thickness/interface_thickness.md`](../../../../doc/interface_thickness/interface_thickness.md)
> - 成分迁移率（`M_c`）→ [`doc/solute_diffusivity/Mc_and_solute_diffusivity.md`](../../../../doc/solute_diffusivity/Mc_and_solute_diffusivity.md)
> - 时间步稳定性（`dt`）→ [`doc/time_step/`](../../../../doc/time_step/)
> - 模型方程 → [`modeling_stage6.md`](modeling_stage6.md)

## 0. 心法：每个参数 ↔ 一个物理量

相场标定**不是拟合，而是一一对应**——把每个自由参数对到一个有实验/MD/CALPHAD 值的物理量上。
按"控制什么"把参数分四层（外加一层"不是材料参数"）。**层与层正交**：界面参数不改平衡成分，
迁移率不改界面厚度，可分层独立标定，互不串扰。

| 层 | 控制什么 |
|---|---|
| ① 热力学 | 平衡落在相图哪个位置 |
| ② 界面静力学 | 界面能多大、界面多宽 |
| ③ 动力学 | 各场演化多快 |
| ④ 亚稳驱动力 | 非晶相在自由能图上的位置 |
| ⑤ 数值 / 工况 | 能否解析、稳不稳、跑什么实验（**非材料参数**） |

## 1. 主表（参数 → 靶子 → 来源 → 公式）

| 层 | 参数（配置键） | 标定靶子（物理量） | 数据来源 | 反解公式 / 说明 |
|---|---|---|---|---|
| ① | `fL,fS,dfLdc,dfSdc` 表 | 平衡相图（液相线/固相线/tie-line） | CALPHAD 评估 | **给定，不标**；相图平衡测试只**验证**（并暴露单位/符号错误） |
| ① | `rho_s`,`c_s` | 固相平衡成分（线化合物钉在化学计量） | 相图 | 线化合物：`c_s`=化学计量、`rho_s`大（强约束）；固溶体应改走 `dfSdc` 表 |
| ② | `w_phi`,`eps_sq` | 晶-液界面能 **σ_SL** + 界面厚度 **δ** | σ：MD / Turnbull；δ：数值选 | `eps_sq = 3·σ_SL·δ`，`w_phi = 6·σ_SL/δ` |
| ② | `w_eta`,`beta_sq` | 非晶-液界面能 **σ_AL** + δ | σ：MD；δ：数值选 | `beta_sq = 3·σ_AL·δ`，`w_eta = 6·σ_AL/δ` |
| ② | `w_ex` | 晶-非晶界面能 **σ_c–a** / 非浸润约束 | MD（晶-玻璃界面能）/ 调试 | 太小→界面混相；太大→液相浸润。无晶-非晶共存时该项不激发 |
| ③ | `M_c` | 互扩散系数 **D** | 实验 / MD（随 T 走 Arrhenius） | `M_c = D / χ`，`χ = ∂²f/∂c²`（热力学因子，由表算） |
| ③ | `M_phi_pref`,`Q_phi` | 晶体**生长速度** U(T) / 界面动力学系数 | MD / 实验生长速率 | `M_phi(T)=M_phi_pref·exp(−Q_phi/RT)`；`Q_phi`≈过冷液扩散/黏度激活能 |
| ③ | `M_eta` | 结构弛豫时间 / 黏度（**唯象**） | 调到合理临界冷却速率 | 无干净实验对应，量级与液体重排同级即可 |
| ④ | `Vm` | 摩尔体积 | 密度 / 表头 | **给定，不标** |
| ④ | `T_g` | 玻璃转变温度 | DSC 实验 / MD | **查表**；进 `dfAmL` 的 `τ=T/T_g` |
| ④ | `alpha` | 非晶→液驱动力幅值（**唯象**） | 调 | 使非晶低温相对液体稳定、但高于晶体（玻璃亚稳） |
| ⑤ | `dx` | 解析界面 | — | 取 `δ/dx ≳ 3–4` 格，**不决定** δ |
| ⑤ | `dt` | 显式稳定限 | — | `dt < min( dx²/(4D), dx²/(4·M_phi·eps_sq) )` |
| ⑤ | `T_start`,`cooling_rate` | 实验工况 | — | 你**施加/扫描**的对象（如临界冷却速率），非标定 |

## 2. 各层细节

### ① 热力学 —— 查表 + 相图验证（不是标定）

`f_L,f_S,∂f/∂c` 来自 CALPHAD（CALPHAD 本身即相图），所以纸面公切线必然复现相图、无信息增量。
跑仿真做"**平衡测试**"额外验证的是：模型装配（`h(φ)` 插值、`μ` 取法、CH–AC 耦合）、代码/单位
（`J/mol` 除 `Vm` 化 `J/m³`）、符号、以及有限界面宽度下的伪效应是否可忽略。

- **测试 A（均匀分解）**：两相区取 `(c₀,T)`，均匀 `c=c₀` + φ 微扰，等温弛豫，看是否分解到 tie-line 端点、体积分数满足杠杆定律。
- **测试 B（平直界面弛豫）**：1D 半液半固，等温弛豫，看**界面是否静止**（驱动力自洽）+ 两侧 bulk 成分对上相图。多个 T 复现整条液/固相线。

`rho_s,c_s` 是代码在 doc 之外加的固相抛物线 `∂f_S/∂c=2ρ_s²(c−c_s)`，**可用平衡测试标定/校正**：
线化合物时 `c_s` 应取化学计量成分、`rho_s` 取大以钉住固相。若换成固溶体，应把它换成真 2D `dfSdc` 表。

### ② 界面 —— σ + δ 反解 `w`,`ε²`,`β²`

平衡界面（双井 `w·φ²(1−φ)²` + 梯度 `(ε²/2)|∇φ|²`，项目约定 `δ=√(2ε²/w)`）给出：

```
σ = (1/6)·√(2·w·ε²)          δ = √(2·ε²/w)
  ⇒  ε² = 3·σ·δ              w = 6·σ/δ
```

- **σ**（材料量）：查 MD，或 Turnbull 经验式 `σ ≈ 0.45·ΔH_f /(N_A^{1/3}·V_m^{2/3})`，`ΔH_f`（熔化焓）从 CALPHAD 表取。
- **δ**（数值量）：真实金属界面亚 nm、网格解析不了，故**人为加宽** δ 到 ≳3–4 格（thin-interface），靠薄界面修正保住动力学。δ 是自由量，选定后 σ 才反解出 `w`,`ε²`。
- 晶用 (σ_SL,δ)→(`w_phi`,`eps_sq`)；非晶用 (σ_AL,δ)→(`w_eta`,`beta_sq`)；同一套公式。
- `w_ex`：来自交叉惩罚 `f_cross = w_ex·φ²η²`，对应**晶-非晶界面**，不在相图上；纯晶-液算例里 η=0 不激发它，需搭晶-非晶共存构型才能标。

> 调参口诀：固定 `ε²·w` → 只改 δ 不改 σ；固定 `ε²/w` → 只改 σ 不改 δ。

### ③ 动力学 —— D 与生长速度反解迁移率

**`M_c`（成分）**：CH 退化为 Fick 给 `D = M_c·χ`，`χ=∂²f/∂c²`（热力学因子，由表算，c→0,1 处发散）。
取目标互扩散系数 `D*` → `M_c = D*/χ`。`D` 一般随 T 走 Arrhenius。详见 Mc doc。

**`M_phi`（晶体 AC，Arrhenius）**：控制晶体前沿推进快慢，物理上是**界面原子附着动力学**（热激活）。
```
M_phi(T) = M_phi_pref · exp(−Q_phi / (R·T))
```
- `Q_phi` ≈ 过冷液体扩散/黏度激活能（玻璃形成体里这一项让低温生长变慢，给出生长速率极大值）；
- `M_phi_pref` 定幅值：跑 1D 平直界面、量前沿速度 `v(ΔT)`，在参考 T 对上 MD/实验生长速度 `U(T)`；多取几个 T 对 `Q_phi`。

**`M_eta`（非晶 AC，常数）**：最唯象。η 非真实相界，无干净实验值；与液体结构弛豫/α-弛豫/黏度同量级，
调到与晶化竞争出合理临界冷却速率即可。

### ④ 亚稳驱动力 —— 定非晶相位置

```
Δf^{Am→L} = R·T·ln(1+alpha)·f(τ)/Vm,   τ = T/T_g
```
- `Vm`：摩尔体积，材料给定，不标；
- `T_g`：玻璃转变温度，查 DSC/MD；
- `alpha`：唯象幅值，调到非晶在低温相对液体稳定但仍高于晶体（玻璃亚稳）。

### ⑤ 数值 / 工况 —— 不是材料参数

`dx` 满足 `δ/dx≳3–4` 解析界面；`dt` 取 CH 与 AC 稳定限的小者；
`T_start,cooling_rate` 是你施加的工况（尤其 `cooling_rate` 是要扫描的临界冷却速率）。

---

## 3. 推荐标定顺序

1. **①** 定/生成 `f_L,f_S,dfLdc(,dfSdc)` 表 → 跑平衡测试 A/B 验证 bulk 落在相图，顺带定 `rho_s,c_s`。
2. **②** 查 σ_SL/σ_AL，选 δ（≳3–4 格）→ 反解 `w_phi,eps_sq,w_eta,beta_sq`；`w_ex` 留到晶-非晶算例。
3. **③** 查 D、生长速度 → 反解 `M_c`、`M_phi(M_phi_pref,Q_phi)`；`M_eta` 唯象调。
4. **④** 查 `T_g,Vm`，唯象定 `alpha`。
5. **⑤** 按 `δ` 定 `dx`、按稳定限定 `dt`；`T_start,cooling_rate` 按要研究的工况设。
