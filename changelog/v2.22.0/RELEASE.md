# v2.22.0 — Eyre 稳定化 shift + 隐式/半隐式示例集

## 摘要

- **`LaplacianOp` 增加稳定化 shift**（第三个构造参数，默认 0）：
  L = D∇² − s·I。这是 Eyre 线性稳定化的落地——把反应项的线性失稳
  部分 −W·s·φ 移入隐式算子（shift = M·W·s，s ≥ max g''），显式余项
  斜率有界，可把 dt 推过显式反应极限。A = (1+σs)I − σD∇² 保持 SPD
  （shift < 0 抛异常）。
- **`develop/implicit_examples/` 示例集**（三个自包含算例 + README，
  已注册根 CMake，二进制落在源目录）：

| 算例 | 拆分 | dt/显式极限 | 内置自检（实测） |
|------|------|------------|------------------|
| `heat_implicit` | 纯隐式扩散（N≡0） | **200×** | 总热量守恒漂移 **0.00e+00** |
| `allen_cahn_semi` | κ∇² 隐式 + 双阱显式 | 20× | 收缩圆 vs 曲率流理论 R²=R0²−2Mκt，偏差 **~2%** |
| `spinodal_ch_semi` | ∇⁴ 隐式 + M∇²f'(c) 显式 | **50×** | 质量漂移 **~5e-12**，max\|c\|→1.02 |

## 示例开发中沉淀的两条定量经验（写进了 README 与代码注释）

1. **AC 的半隐式收益由刚度比决定**：dt_react/dt_diff = 2δ²/dx²。
   界面宽（δ=8dx → 比值 128）时扩散主导，20× 稳且准；界面薄
   （δ~2dx）时反应与扩散同阶，收益天然有限——这是界面解析物理
   决定的，不是求解器缺陷。CH 的 ∇⁴ 刚度才是半隐式大赚的场景。
2. **稳定化的时滞代价可量化**：dt·M·W·s ≳ 1 时界面动力学被人为拖慢
   约 (1 + dt·M·W·s) 倍（示例开发中实测 4× 减速与该公式吻合）——
   **稳定 ≠ 准确**，定量计算要盯 dt·M·W。
