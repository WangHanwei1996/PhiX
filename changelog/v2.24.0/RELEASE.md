# v2.24.0 — 数值格式库扩充 + BCBatch 角格填充

## 摘要

格式家族补全（全部接入字符串调度与 ghost 校验，收敛阶经加密序列实测）：

| 格式 | 类型 | ghost | 实测阶 |
|------|------|-------|--------|
| **CD6** | 六阶中心差分（lap/grad） | 3 | **5.99 / 5.99** |
| **UW2** | 二阶单侧迎风（对流） | 2 | **1.97–1.99** |
| **WENO5** | 五阶 HJ-WENO（Jiang-Shu，对流） | 3 | **4.78–4.91**（光滑场） |
| **Iso27** | 3D 各向同性 27 点 Laplacian | 1 | 二次函数**精确**（<1e-9） |

**ghost 相关修改（本版重点）**：`BCBatch` 增加**角格填充第二遍 kernel**
——各描述符把切向范围扩进"轴序更高"的 ghost 带（X BC 扩进 y/z 角区、
Y 扩进 z），第一遍填好的边带作为源，角格自动获得正确组合（周期角 =
对角周期像，NoFlux 角 = 边 ghost 的镜像），且各描述符写区仍互不相交。
**Iso9/Iso27/anisoDiv 这类读对角邻居的模板从此在边界也正确**
（v2.23.0 的角格警告解除）。逐 BC 顺序路径保持旧行为（不填角）。

## API

```cpp
lap(f, "CD6", kappa);  grad(f, 0, "CD6");     // ghost >= 3
lap(f, "Iso27", D);                            // 3D，要求 dx=dy=dz
adv(u, f, "UW2",   -1.0);                      // ghost >= 2
adv(u, f, "WENO5", -1.0);                      // ghost >= 3
```

- BC kernel 本就按 ghost 宽度循环填层，ghost=3 无需额外改动（已验证）；
  `setRHS` 的逐项 ghost 校验对新格式自动生效；
- **守恒性说明**（写进 Advection.h）：三种对流格式都是导数（HJ）形式；
  UW1 的线性单侧差分可 telescoping，常速周期输运严格守恒；UW2/WENO5
  的（非线性）组合不 telescoping——质量只保到截断精度（实测 WENO5
  阶跃输运 80 步漂移 <0.5%）。要严格守恒请走 face-flux 链。

- **新增 `conv_advection`**：UW1/UW2/WENO5 阶 0.99 / 1.97 / 4.9；
- `module_schemes_ext` 扩充：Iso27 对二次函数逐点精确（∇²=12，<1e-9）；
  WENO5 阶跃输运基本无振荡（过冲 <5e-3）+ 截断级守恒；
- `module_bc_batch` 更新：非角区与顺序路径逐位一致 + **角格自洽断言**
  （角 ghost == 其周期像）。

全量 ctest **31/31**，FLOAT 3/3。

## 兼容性

- 既有格式与调用不变；未知格式名的报错信息列出全集；
- **行为变化**：`BCBatch`（即所有库内求解器路径）现在填角格——此前
