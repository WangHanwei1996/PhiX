# v2.27.0 — 3D 立方各向异性（`anisoDiv3D`）

## 摘要

各向异性模块补上三维：Karma–Rappel 立方形式（晶轴对齐），闭式变分
导数通量，**全代数无超越函数**，单融合 kernel（每格 6 面寄存器内
现算，保守）：

```
a(n) = 1 − 3ε + 4ε·(n_x⁴ + n_y⁴ + n_z⁴),   n = ∇φ/|∇φ|
J_i  = W0²·a·∂_iφ·[ a + 16ε·(n_i² − S) ],  S = Σ n_k⁴
```

## API

```cpp
Aniso3DParams ap;  ap.W0 = W0;  ap.eps = 0.05;   // ε₄，校验 [0, 0.3)
eqPhi.setRHS( anisoDiv3D(phi, ap) + ... );        // dim==3, ghost>=1
anisoFactor3DOnGPU(phi, aField, ap);              // 格心 a(n)，供 τ(n)
aniso::factor3D(px, py, pz, eps);                 // device 助手
```

- z 不变场上**严格退化为 2D 的 m=4 形式（同一 ε）**——两套独立实现
  互为交叉验证（测试实测逐格一致 3e-13）；
- 凸性界 ε ≲ 1/15 与 2D m=4 相同（文档注明，validate 硬界 0.3）；
- 边界正确性依赖 v2.24.0 的 BCBatch 角/棱填充：本模板的切向读数只到
  **面内对角（棱 ghost）**，两遍填充恰好覆盖；三重角不被读取；
- 晶粒旋转（非轴对齐）为预留扩展（∇φ 旋入晶系、通量旋回，接口注明）。

## 开发中修掉的数值 bug（2D 也受益）

守恒测试的紧支撑 bump 暴露出**下溢/上溢 NaN**：梯度极小但未到守卫
阈值时（p² ~ 1e-200），p⁴ 下溢为 0 而 1/p⁴ 上溢为 inf → 0×inf = NaN。
2D 的复数幂递推同样潜伏（p²ᵐ 下溢）。修复：**先归一化再乘方**——
3D 用方向余弦平方 n_i² = p_i²/|p|² 构造 S，2D 复数幂改为单位方向
递推（|z|≡1），全程 O(1)；守卫阈值提到 1e-150（对 p² 下溢留裕量）。

## 测试

`module_anisotropy3d`（已注册 ctest）：

1. ε=0 严格退化为 W0²·CD2 Laplacian（3D，<1e-9）；
2. **z 不变场 3D == 2D m=4** 逐格交叉验证（3.1e-13）；
3. 守恒性：紧支撑 C∞ bump（r≥0.35 严格为零 → 边界通量精确为零），
   全域和纯测内部 telescoping（通过）；
4. GPU==CPU 双路径（Term 与 factor）；
5. a(n) 方向点检：<100>→1+ε、<110>→1−ε、<111>→1−(5/3)ε、ε=0→1；
   ε≥0.3 与 2D 网格误用抛异常。

全量 ctest **33/33**，FLOAT 3/3。
