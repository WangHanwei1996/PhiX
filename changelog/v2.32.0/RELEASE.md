# v2.32.0 — LBM 障碍掩码 + 速度入口 / 压力出口（PFHub 基础设施 ④）

## 摘要

BM5（Stokes 流）需要的三件边界能力：

- **`setObstacleMask(mask)`**：内部无滑移障碍——mask ≥ 0.5 的格子为
  固体，流动步在其表面半程反弹；固体格分布冻结、宏观量报 u=0；
- **`setVelocityInlet(axis, side, uN[, uT])`**：Zou–He 速度入口，四侧
  通用，逐边界格剖面（抛物入口直接传数组）；
- **`setOutflow(axis, side, rho0=1)`**：Zou–He **压力出口**（锚定密度、
  法向速度自由）。

## 开发中修掉的物理坑（记录）

第一版出口用零梯度拷贝——诊断显示**密度无界增长**（1.55→5.44，
3×30000 步）：速度入口 + 纯 Neumann 出流没有任何条件锚定压力水平，
每步微小质量失衡持续积分（LBM 经典陷阱）。换成压力出口后 ρ 锚定
1.000、沿程线性压差驱动流动（正确物理）、30000 步即完全稳态。
另一个指标教训：可压缩 LBM 里沿程守恒的是**质量通量 Σρu**（Σu 随
压力梯度变化）——测试断言已按此修正。

## 实测（module_lbm 扩充）

| 检验 | 结果 |
|------|------|
| 入口/出口 Poiseuille（无体力，抛物入口） | 下游剖面偏差 **3.5e-3**，质量通量沿程漂移 **2.2e-4** |
| 通道中央 8×8 方块绕流 | 固体格速度精确为 0；旁路加速；上下镜像对称 **<1e-10**；无 NaN |
| 既有体力 Poiseuille / 黏度动态 / 封闭系质量守恒 | 原样通过 |
