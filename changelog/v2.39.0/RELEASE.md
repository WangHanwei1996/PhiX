# PhiX v2.39.0 发布说明

## PFHub Benchmark 5（Stokes 通道流）复现：变体 5a/5b 跑通

### 新求解器 `applications/solvers/LBM_channel/2D`

首个基于 v2.32.0 LBM 模块的配置驱动求解器：

- D2Q9 BGK，半程反弹上下壁，Zou-He 抛物线速度入口（逐格子点剖面）
  + Zou-He 压力出口，可选椭圆障碍掩码；
- 物理↔格子单位换算全部由配置推导（dx、dt、ρ、μ → τ、u_lat、a_lat；
  压力换算 p = c_s²Δρ·ρ_phys·(dx/dt)²）；
- 稳态自动判停（max|Δu| < 1e-8·max|u|）；
- 输出 PFHub 要求的两条截面 CSV（x=7、y=5：坐标、u_x、u_y、p）。

### 重力的正确打开方式（已记录）

恒定体力在不可压缩流中被静水压 p_h=ρg·(r−r_ref) **精确**平衡，
速度场不变；LBM 的均匀密度 Zou-He 出口与静水密度梯度不相容——
直接以 Guo 强迫加重力会驱动 ~7 倍量级的伪环流
（实测 max|u| 0.066 vs 正确 0.009）。求解器改为：动力压 LBM 内解，
静水分量经可选 `hydrostatic` 配置节在输出端解析叠加。

### 验证（变体 a，对解析泊肃叶解）

- u_x(y) 剖面 max 偏差 **0.05%**；max u_x = 0.009017（理论 0.009，
  半程反弹离散效应 0.19%）；
- dp/dx = −0.002004（理论 −2μu_max/h² = −0.002，0.2%）；
- dp/dy = −0.10000（静水 ρg_y，精确）；p(30,5)=0.1000（精确）。

变体 b（椭圆障碍）：6 万步收敛，max u_x=0.0218 m/s（间隙加速，
通量守恒一致）。Re≈5.4，LBM（NS 求解器）处于弱惯性 Stokes 区。
