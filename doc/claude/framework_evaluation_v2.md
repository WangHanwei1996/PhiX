# PhiX 框架评价（第二版）：v2.17.0 状态下的缺口、优劣势与优化路线

> 评估日期：2026-07-03 · 分支 feature/core-upgrades @ v2.17.0（约 1.4 万行库代码，26 项 ctest）
> 前版评估：[framework_evaluation.md](framework_evaluation.md)（基于 v2.8.0 前夕）
> 运行环境：RTX 5080（16 GB，消费级 Blackwell，FP64:FP32 = 1/64），WSL2
> 评估理念：**性能第一，用户友好第二**

## 2. 与成熟套件的剩余缺口（更新版）

| 模块 | 成熟套件做法 | PhiX 现状 | 缺口严重度 |
|---|---|---|---|
| **调度层效率**（launch/同步/拷贝） | kernel 融合、图执行、异步流水 | 12 处每步级 `cudaDeviceSynchronize`；BC 逐场逐面 launch；时间层轮转仍是全量 D2D memcpy（`ScalarField.cu`）；EvalPlan Stage 5 Local 融合未实现；**CG 每次迭代 2 个点积 = 2 次设备→host 同步往返** | ★★★★★（见 §4，已是唯一的性能大头） |
| 二阶 IMEX / 能量稳定格式 | SBDF2/CNAB2、Eyre 稳定化预设 | 仅一阶 BE/FE 对；Eyre 需用户自己往 L 加项 | ★★★☆ |
| 预条件子 / 多重网格 | Chebyshev、GMG、AMG | CG 裸跑（当前常系数算子 7–24 迭代够用；变系数/大 σ 时会爆） | ★★★（按需） |
| 变系数隐式算子 | ∇·(M(φ)∇·) 隐式化 | 隐式算子仅常系数；M(φ) 项只能显式（面通量链） | ★★★ |
| 多 GPU / MPI | halo exchange + NCCL | 无；16 GB 显存即规模上限 | ★★★（问题规模逼近时升级） |
| 高阶对流格式 | WENO/TVD | 仅一阶迎风；CD4 未接入 Expr/Fused 层 | ★★☆ |
| 非均匀网格 / AMR | 拉伸网格、块 AMR | 仅均匀网格 | ★★☆（相场界面遍布全域时收益有限） |
| 并行/异步 IO + HDF5 | HDF5+XDMF、写线程 | 自定义格式、主线程同步写 | ★★ |
| CI 自动化 | GitHub Actions 全量回归 | 测试齐全但无 CI（GPU runner 门槛） | ★★ |
| 完整 checkpoint | RNG/求解器全状态入档 | warm-restart 仅场文件 | ★☆ |
| DSL 层收敛 + 文档 | 单一表达层 | 三层 DSL 共存；doc/ 若干仍是 legacy API | ★★（维护性债务） |

一句话：**算法层地基已补齐，剩余缺口集中收敛到"调度层效率"一项独大**，
其余均为按需扩展。

## 3. 当前优势

1. **算法能力对齐甚至超过同类**：显式（Euler/RK4/自适应 dt）+ 半隐式
   IMEX（dt 解除 dx²/dx⁴ 约束）+ matrix-free CG，再叠加 KKS/反截留流的
   定量相场件——通用 FD 套件没有后者，相场专用套件（MOOSE/PRISMS-PF）
   没有 PhiX 的编译期 kernel 融合（FusedTerm 多输出单 kernel）。
2. **验证文化成型**：26 项 ctest 含收敛阶回归（曾抓出 Iso9 权重真 bug）、
   离散特征值构造的机器精度积分器测试（9.5e-17 一致性）、守恒/单调性/
   GPU==CPU 双路径校验。改格式、改积分器不再"裸奔"。
3. **运行时自治**：设备端归约 + NaN 哨兵 + 自适应 dt——不再"盲飞"，
   诊断不再整场过 PCIe。
4. **性能可测可比**：`bench_stencil` 基线 + NVTX/lineinfo 钩子 + 双精度
   开关，任何优化都有前后对照数字（这正是本文 §4 论断的数据来源）。
5. 原有优势保持：分层干净、~1.4 万行单人可掌控、面向相场的保守面通量
   /Gibbs 投影/自由能表格域件、JSONC 配置 + makePhi 工作流。

## 4. 当前劣势

1. **调度层开销现在是唯一的性能大头，且被半隐式放大**。基线数据：
   完整显式 Euler 步比裸 stencil kernel 慢 2.8–3.7×；FLOAT 换来的
   kernel 级 1.6–3.1× 提速在完整步上只剩 1.2×——瓶颈不在算而在调度
   （每步同步、BC 逐面 launch、时间层 D2D 拷贝）。半隐式使其更突出：
   **CG 每次迭代含两个点积，每个点积是一次设备→host 同步往返**，
   6–24 次迭代/步 = 12–48 次往返/步，WSL2 上 launch/同步开销又高于
   原生 Linux。算法层赚到的 50–100× 步长收益，正在被每步变贵蚕食一角。
2. **半隐式层的三个天花板**：一阶精度（BE/FE）；单方程（φ+c 耦合需
   手工算子分裂时序）；隐式算子仅常系数（退化迁移率 M_c(φ) 只能留在
   显式侧，刚性未完全卸载）。
3. **自适应 dt 未接入半隐式路径**——恰恰是半隐式最受益的场景
   （dt 可放开到精度约束而非稳定性约束）。
4. CD4/迎风只在 Term 层可用，ExprTree/FusedTerm 不认识；三层 DSL
   的维护负担依旧。
5. 单 GPU 16 GB、均匀网格、同步 IO、无 CI——各自都还不疼，但都有
   明确的触发条件（规模、几何、输出频率、协作者数量）。

## 5. 性能第一理念下的优化优先级（更新排序）

| # | 优化项 | 做法 | 预期收益 | 工作量 |
|---|---|---|---|---|
| 1 | **调度层总攻**（前版 #2，现升为绝对第一） | ① 时间层指针交换（零风险白捡，仍未做）；② BC 批处理（一场一 kernel 或全场一 kernel）；③ EvalPlan Stage 4/5（流化 + Local 融合）；④ 稳态时间步 CUDA Graph 捕获重放 | 完整步 2–3×（中小网格更多，WSL2 加成）；有基准可即时验证 | 中 |
| 2 | **CG 去同步** | 点积结果留在设备端（cudaGraph + 设备端标量），或合并两点积为单次归约（pipelined CG）；CG 迭代体 Graph 化 | 半隐式每步 12–48 次 PCIe 往返 → 1–2 次；对小网格 CG 是数量级 | 中 |
| 3 | **SBDF2/CNAB2 二阶 IMEX** | 在 SemiImplicitSolver 上加一个历史层 + 系数切换；CG 复用 | 同精度下 dt 再放大 5–10×，或同 dt 精度平方级提升；实现小 | 小–中 |
| 4 | **自适应 dt 接入半隐式** | rate-limited 控制器复用（σ=dt 在算子外，本来就零成本换 dt）；加 CG 迭代数反馈（迭代数暴涨 → dt 回调） | 半隐式的 dt 自动逼近精度约束 | 小 |
| 5 | **Eyre 稳定化预设 + 变系数隐式算子** | L 加常系数 s∇² 预设一行配置；变系数 ∇·(M(φ)∇·) 算子（kernel 现成思路，CG 仍 SPD） | CH 超大 dt 无条件稳定；退化迁移率刚性卸载 | 中 |
| 6 | 预条件子（Chebyshev → GMG） | 仅当 #5 变系数/大 σ 使迭代数失控时启动 | 按需 | 中–大 |
| 7 | CD4/迎风接入 Expr/Fused 层 + DSL 三层收敛 | 顺手于 Stage 5 重构一起做 | 用户友好为主 | 中 |
| 8 | 异步 IO；多 GPU | 触发条件驱动（输出频繁 / 显存撞墙） | 场景性 | 小 / 大 |

刻意不做的判断维持：AMR、Newton 全隐式、CPU 并行套件。

**验收锚点**：优化 #1、#2 完成后，`bench_stencil` 的 "euler step" 行
应逼近 "lap CD2" 行（差距 <1.5×），FLOAT 完整步提速应从 1.2× 回升到
接近 kernel 级的 1.6×+；半隐式每步 wall time 应以 CG kernel 时间为主。
这三个数字就是下一轮的成绩单。

## 6. 建议路线图

1. **速赢周**：时间层指针交换 + BC 批处理 + 自适应 dt 接入半隐式
   （#1①② + #4）——全部有现成测试护航。
2. **调度月**：EvalPlan Stage 4/5 + CUDA Graphs + CG 去同步
   （#1③④ + #2），以 bench_stencil 前后对照验收。
3. **算法补完**：SBDF2 + Eyre 预设 + 变系数隐式算子（#3、#5），
   GFA_FeB 迁移到 KKS + 半隐式作为实战验收算例。
4. **远期触发式**：多 GPU（显存撞墙时）、HDF5/异步 IO（输出成为
   瓶颈时）、GMG（迭代数失控时）。

## 附：影响评估准确性的不确定项

- "CG 点积同步是半隐式主要开销"是**结构推断**（每迭代 2 次 D2H 往返
  ×6–24 迭代），未经 Nsight 时间线证实——动手 #2 前先 profile 一次
  半隐式步。
- "完整步 2–3× 收益"外推自显式基线（2.8–3.7× 开销比）；半隐式步的
  开销构成不同，收益可能偏离。
- SBDF2 对 CH 线性分裂的稳定域比 BE 窄（二阶 IMEX 常见代价），
  #3 落地时需按 Ascher–Ruuth–Wetton 参数化并用现有 CH 测试回归。
- FLOAT 模式仍未做过相场长时守恒验证（冒烟级），GFA 生产计算继续
  建议 DOUBLE。
- 本文全部实测数字来自 RTX 5080 + WSL2 + PTX JIT（arch 75 编译），
  原生 Linux / 数据中心卡上的开销比会不同（通常更小）。
